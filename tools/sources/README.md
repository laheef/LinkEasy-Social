# Offline design build sources

- `logo-source.png`: the original black-background 3D mark supplied by the project owner, retained without redesign. `build_logo.py` preserves the near-black ribbon base.
- `si/*.svg`: the exact Simple Icons path geometry used in the shipped platform sprite, extracted into standalone SVGs for reproducible builds. Simple Icons is CC0; brand trademarks remain with their respective owners. Five platform monograms are generated by the build script.
- `Inter.ttf` and `Inter-OFL.txt`: Inter variable font and SIL Open Font License from google/fonts, used for the OG-image build. Website WOFF2 files are already under `public/assets/fonts/`.

These sources are local build inputs only. They are not fetched at runtime. The generated images/SVG sprites are already included, so a server deployment does not require Python or Node.
